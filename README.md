专为 **《边狱公司》（Limbus Company）** Android 端打造的免 Root 沙箱汉化启动器。  
无需修改正版游戏安装包签名，也无需反复卸载重下十余 GB 数据，即可在独立虚拟容器中体验高还原度中文界面与 Google 账号直登服务。

## 📦 下载与快速上手

- **适用设备**：Android 12 ～ Android 17，主流 64 位（`arm64-v8a`）手机，建议预留 **15～20 GB** 以上可用存储空间
- **下载地址**：前往 [**Releases 页面**](https://github.com/KONGT1AO/Limbus-Company-Localization-Sandbox/releases) 下载最新 `LimbusLocalizer-v*-arm64-v8a.apk`

### 初次使用四步流程
1. **准备正版与启动器**：先在手机中安装官方正版《边狱公司》，再安装本启动器 APK（同步后**请保留宿主机正版 APP 不要卸载**；后续遇到商店大版本更新时，更新正版 APP 后进入启动器 **「03 维护」** 点击 **「手动重新同步宿主机游戏 APK」** 即可）。
2. **放行系统权限**：打开启动器，在 **「01 启程」** 页点击 **「一键允许后台运行」** 放行省电限制（防止 Google 登录跳转或切后台时被系统回收）；若需使用公共热投递目录，可在 **「02 汉化」** 页点击 **「授权访问公共热投递目录」** 开启所有文件访问权限。
3. **导入中文汉化包**：在 **「02 汉化」** 页支持以下任一方式：
   - 点击 **「导入 .zip / .7z」** 或 **「导入文件夹」** 直接导入本地汉化资源；
   - 将汉化包放入手机公共目录 `Download/LimbusLocalizer` 后，点击 **「扫描热投递专区并对齐」** 一键读取；
   - 前往 **「03 维护 → 汉化源连接」** 点击 **「在线下载并更新汉化」** 从指定源拉取。
4. **启动游戏**：回到 **「01 启程」** 页，点击 **「进入《边狱公司》」**，完成首次环境校验、Google 登录与资源下载后即可开始游玩（若首次导入时游戏尚未下载过热更资源，进游戏下载完资源后重启一次即可挂载中文）。

> [!IMPORTANT]
> **更新启动器请直接下载新版 APK 覆盖安装，千万不要先卸载旧版！**  
> 本应用所有版本均保持统一包名（`io.limbuspe.box`）与签名证书，覆盖安装后会完整保留沙箱内已下载的十几 GB 游戏资源与账号登录状态。

## 🌟 主要特点

- **免改包更安全**：不篡改官方正版 APK 二进制文件与原厂签名，全部汉化注入均在独立隔离容器内完成。
- **周四热更新无忧**：采用纯净游戏本体层与汉化叠加层分离架构，每周例行更新写入游戏层后，汉化索引仍自动匹配生效，无需每次重新手动打补丁。
- **高还原度中文渲染与内置双字重字库**：
  - 内置 **更纱黑体（Sarasa）Bold / Regular** 双字重兜底字库，即便导入不含 `.ttf` 字体文件的小体积汉化包也能保持清晰粗体不缺字，战斗超长技能横幅与人格卡标题均完整居中排版；
  - 完整还原 **第 6 章 / 第 10 章** 等剧情中带富文本标签、彩色渐变与逐字打字机特效的特殊台词演出；
  - 镜牢随机事件判定、选项效果与 E.G.O 饰品获取名称完整汉化呈现，UI 贴图与文字层级清晰准确。
- **支持 Google 账号直登**：内置 microG 与基础验证支持环境，可在容器内直接登录与 Steam 端互通的 Google 账号，方便手机随时清体力、下镜牢。
- **多汉化包管理与公共热投递**：支持任意符合官方自定义本地化接口规范的 `.zip` / `.7z` 压缩包与目录结构，支持通过 **「📑 切换 / 管理汉化包」** 实现多包共存切换与清理，并提供公共目录 `Download/LimbusLocalizer` 自动对齐扫描。
- **换机资源迁移与防误触横屏锁定**：
  - 在 **「03 维护 → 资源迁移」** 支持 **「迁出资源 ZIP / 迁入资源 ZIP」**，换新手机或备份重装时无需重新下载十余 GB 游戏热更资源（并自动剔除设备绑定缓存避免冲突）；
  - 在 **「03 维护 → 横屏方向锁定」** 支持独立于系统竖屏锁定，一键设置为 **「锁定反向横屏 (推荐)」**（音量键朝上避免双手握持误触）或 **「锁定常规横屏」**。

## ❓ 常见问题

- **Q：更新启动器或游戏大版本时，需要重新下载十几 GB 游戏资源吗？**  
  不需要。更新启动器时**直接覆盖安装**即可继承全部容器数据；商店推出新大版本 APK 时，只需更新手机原版《边狱公司》，再进启动器 **「03 维护」** 点一下 **「手动重新同步宿主机游戏 APK」** 即可。
- **Q：如何把已经下载好十几 GB 资源的容器迁移到新手机？**  
  在旧手机启动器的 **「03 维护 → 资源迁移」** 点击 **「迁出资源 ZIP」** 导出资源备份包，传到新手机后在启动器同位置点击 **「迁入资源 ZIP」** 即可恢复，无需重下热更数据。
- **Q：为什么把汉化包放进了 `Download/LimbusLocalizer`，列表里却没有显示？**  
  在 Android 11 及以上系统覆盖/重装后，需先在 **「02 汉化」** 页点击 **「授权访问公共热投递目录」** 授予「所有文件访问权限」，返回后再次扫描即可立刻识别。
- **Q：遇到文字异常、闪退或黑屏怎么反馈？**  
  请在启动器 **「03 维护 → 诊断与支持」** 点击 **「导出运行诊断包（ZIP）」**（程序已自动过滤账号凭据等隐私数据），连同机型系统信息与问题截图一并提交至 GitHub Issues。
